1. Source

Browsers only allow this when the image's website permits cross-origin access (CORS). Many sites don't: if it fails, right-click the image → Save image as… and upload the file instead. (The Python/Windows edition fetches server-side and works with more sites.)

5. Zones

Choose the Zones tool and drag on the image to draw a rectangle. Drag a zone to move it, drag its handles to resize. A zone that is switched off removes every contour whose centre (centroid or bounding-box centre) is inside it from the DXF.
